First ZaiqoM-MeetingHelper desktop release with project-aware meeting assistance, source navigation, MCP management and eight workspace appearances.

- IBM, Liquid Glass, Apple, Linear, Notion, Material, GitHub and Terminal appearances; independent light/dark/system mode.
- New ZaiqoM identity across the app and desktop icons.
- Request-scoped answers, cancellation, visible retry and queued questions.
- Query-based knowledge search, atomic indexing and source references.
- MCP tools for settings, projects, meetings, providers and device diagnostics.
- Session credential caching to reduce repeated Keychain reads.

## Downloads

- Windows x64: NSIS `.exe` installer; WebView2 required (installer handles setup).
- macOS Apple Silicon (ARM64), macOS 13+: `.dmg`.
- Linux x64: `.AppImage` and Debian/Ubuntu `.deb`.
- Verify downloads against `SHA256SUMS.txt`.

## Validation and known limits

Installers are built from this exact tag, with frontend, MCP, Rust and browser checks in the platform build jobs. Browser tests use mocked native IPC. Real meeting audio, 60-minute endurance, retrieval/answer quality and native glass compositing remain acceptance work; this release does not claim those checks passed.

These initial packages are not signed with a trusted Apple Developer or Windows publisher certificate; macOS notarization and signed automatic updates are not configured. OS publisher warnings may appear. Existing settings and credential storage identity are preserved. An OS Keychain prompt may still occur on first access by a newly built app.
